Sistema de Reservas - Hotel Paraíso Real
Descripción

Este proyecto corresponde a una aplicación de consola desarrollada en JavaScript utilizando Node.js y Programación Orientada a Objetos.

El sistema permite gestionar las reservas de habitaciones del Hotel Paraíso Real.

Funcionalidades
Registrar huéspedes.
Consultar habitaciones.
Registrar reservas.
Seleccionar planes de alimentación.
Calcular el valor total de las reservas.
Consultar las reservas registradas.
Mostrar el estado de las habitaciones.
Clases utilizadas
Huesped
Habitacion
Alimentacion
Reserva
Hotel
Tecnologías
JavaScript
Node.js
Programación Orientada a Objetos
Ejecución

Para ejecutar el programa se debe tener instalado Node.js.

Desde la terminal:

node SistemaReservasHotel.js
